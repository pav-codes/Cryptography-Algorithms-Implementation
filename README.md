# Cryptography-Algorithms-Implementation
Objective: Implement popular cryptography algorithms like AES, RSA, or SHA to understand encryption and decryption processes

## [AES](AES.py) - symmetric encryption algorithm
It uses the same key for encryption and decryption

## [RSA](RSA.py) - asymmetric encryption algorithm
It uses 2 keys:
- Public key for encryption
- Private key for decryption

## [SHA](SHA.py) - hashing algorithm
it has no decryption key. It's mainly used for passwords, digital signatures
